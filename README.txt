===================================================
CALCULA AÍ - Versão Web & Mobile (Migração de Pygame)
===================================================

Como Inicializar a Aplicação:
-----------------------------
1. Extraia o conteúdo deste arquivo ZIP em uma pasta.
2. Dê um duplo clique no arquivo 'index.html' para abrir o jogo direto no seu navegador.
   * Não é necessário instalar nada! Funciona offline em qualquer navegador moderno (Chrome, Firefox, Edge, Safari).
3. Para jogar no celular: Você pode transferir estes arquivos para o seu celular ou hospedá-los gratuitamente em plataformas como GitHub Pages, Vercel ou Netlify, e abrir o link no navegador do smartphone.

Controles:
----------
* No Computador (Teclado):
  - Seta Esquerda / Direita: Move o bloco para os lados.
  - Seta para Baixo: Acelera a queda do bloco.
  - Barra de Espaço: Inverte a posição dos blocos (se for um bloco duplo).
  - CTRL (Esquerdo ou Direito): Queda rápida instantânea.
  - Tecla P: Pausa / Despausa o jogo.
  - Tecla R: Reinicia o jogo na tela de Game Over.

* No Celular (Touch):
  - Use os botões virtuais que aparecem logo abaixo do tabuleiro de jogo para se mover, inverter, dar queda rápida ou pausar.
